VISILUX · Integracion de las APIs en los flujos reales (2026-11-23, version 5: triggers sin FROM DUAL + trigger de precios)
====================================================================

INSTALACION
  1. Copiar y pegar el contenido de este zip en la RAIZ del proyecto (reemplazar archivos).
  2. En phpMyAdmin (base visilux, pestaña SQL) ejecutar:
       database/sql/2026_11_23_1_login_obligatorio_log_acceso.sql   (VERSION 5: trigger 1 con IF, sin FROM DUAL)
       database/sql/2026_11_23_2_api_triggers.sql                   (VERSION 5: triggers con IF, sin FROM DUAL;
                                                                     trigger 4 nuevo: historial de precios de productos)
       Los dos se pueden volver a ejecutar sin problema (borran y crean los triggers). Usan DELIMITER $$.
       database/sql/2026_11_23_3_empresa_departamento.sql   (agrega la columna empresa.departamento)
  3. En la terminal: php artisan optimize:clear
  4. Pruebas: php artisan test --filter=ApisExternasTest   (13 pruebas)
  No hay archivos para eliminar. Si ya ejecutaste el SQL de la version anterior, no lo vuelvas a ejecutar.

APIS USADAS (los mismos endpoints de public/apis/)
  - Departamentos/ciudades: https://api-colombia.com/api/v1/Department  y  /api/v1/Department/{id}/cities
  - Indice UV Ibague:       https://api.open-meteo.com/v1/forecast?...&current=uv_index&daily=uv_index_max
  - Festivos Colombia:      https://date.nager.at/api/v3/PublicHolidays/{anio}/CO

ARCHIVOS NUEVOS
  public/apis/consultar_api.php
      La funcion consultarApi($url) con cURL, en un solo lugar. La usan los 3 archivos de public/apis/ y Laravel.
  app/Support/ApisExternas.php
      Llama a las 3 APIs (con consultarApi), revisa que la respuesta tenga el formato esperado y la guarda en cache
      (departamentos/ciudades/festivos 1 dia, UV 10 min). Si una API falla devuelve null y la pantalla muestra un aviso.
  app/Http/Controllers/ApiExternaController.php
      Dos rutas JSON para el JavaScript: ciudades de un departamento y "¿esta fecha es festivo?".
  resources/views/includes/rayos-uv.blade.php
      Seccion informativa de rayos UV del inicio: indice actual, nivel con color, consejo y boton a gafas con proteccion UV.
  database/sql/2026_11_23_3_empresa_departamento.sql
      ALTER TABLE empresa ADD COLUMN departamento.
  tests/Feature/ApisExternasTest.php
      11 pruebas: departamentos, ciudades (y su ruta), festivos, calendario de festivos, indice UV y la seccion UV.
      No usan internet: simulan la respuesta de cada API con el mismo formato real.
